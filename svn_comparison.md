# Сравнение Git и SVN

1. Почему в Git ветвление дешёвое, а в SVN дорогое?
В Git ветка — это просто указатель (ссылка) на коммит, создаётся мгновенно и не копирует файлы.
В SVN ветка — это физическое копирование целой директории на сервере, что медленно и занимает место.

2. Можно ли в SVN сделать коммит без интернета?
Нет. SVN — централизованная система, коммит сразу отправляется на центральный сервер,
поэтому без подключения к серверу закоммитить изменения нельзя.

3. В каких сценариях SVN может быть предпочтительнее Git?
В legacy-проектах с давно устоявшейся инфраструктурой (например, в банках и госсекторе),
где сотрудникам проще права доступа настраивать централизованно по каталогам,
и переход на Git экономически не оправдан.
