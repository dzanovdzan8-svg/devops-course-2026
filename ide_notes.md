# VS Code vs Терминал

Удобно в VS Code:
1. Визуальный diff — сразу видно, что изменилось построчно
2. История коммитов в виде графа
3. GitLens показывает, кто и когда менял строку (git blame)

Удобнее в терминале:
1. Быстрые сложные операции вроде rebase -i, cherry-pick, работа по SSH на сервере без GUI
